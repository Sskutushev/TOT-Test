# Master Journal: TOT Website Project

## 1. Обзор проекта

- **Тип:** Статический веб-сайт.
- **Технологии:** HTML, CSS. Папка `js` существует, но на данный момент пуста.
- **Цель:** Этот журнал служит для быстрого введения в курс дела о структуре и рабочих процессах проекта при каждой новой сессии.

## 2. Структура файлов

- **`/` (корневая директория):** Содержит все HTML-страницы сайта (например, `index.html`, `profile.html` и т.д.).
- **`css/`:** Содержит все файлы стилей. Основной файл - `styles.css`.
- **`js/`:** Предназначена для JavaScript-кода. В настоящее время пуста.
- **`img/`:** Содержит все изображения и иконки, используемые на сайте.

## 3. Рабочие процессы и соглашения

### Как внести изменения:

- **Изменение стилей:**
  1. Откройте `css/styles.css`.
  2. Внесите необходимые правки в существующие стили или добавьте новые классы.

- **Добавление новой страницы:**
  1. Создайте новый `.html` файл в корневой директории (например, `new_page.html`).
  2. Заполните его базовой HTML-структурой, скопировав ее из существующего файла (например, `index.html`) для сохранения единообразия.
  3. Убедитесь, что новый файл ссылается на `css/styles.css`.
  4. Добавьте ссылки на новую страницу с других релевантных страниц.

- **Добавление интерактивности (JavaScript):**
  1. Создайте новый `.js` файл в папке `js/`.
  2. Подключите этот скрипт в нужном HTML-файле перед закрывающим тегом `</body>`, используя `<script src="js/your_script_name.js"></script>`.

- **Добавление изображений:**
  1. Поместите новый файл изображения в папку `img/`.
  2. Используйте относительный путь `img/image_name.svg` в HTML или CSS.

## 4. Ключевые файлы

- **`index.html`:** Главная страница сайта.
- **`css/styles.css`:** Единственный файл стилей, определяющий весь внешний вид сайта.
