# Проект "ТОТ" (The Online Technologies)

Этот документ содержит всю необходимую информацию для разработки, поддержки и развертывания проекта "ТОТ".

## О проекте

**"ТОТ"** — это аббревиатура, которая расшифровывается как **"Торгуй, Обучай, Твори"**. На английском языке концепция звучит как **"Trade, Observe, Thrive" (TOT)**.

"ТОТ" — это многофункциональная, многогранная платформа для обучения, трейдинга, инвестиций, консультаций и многого другого из сфер инвестиций и образования. Она предназначена для создателей и пользователей продуктов в сфере финансовых технологий и включает в себя маркетплейс для алго-ботов и образовательных курсов, социальную ленту для обмена опытом, профили экспертов и многое другое.

## Технологический стек

- **Фронтенд:** React.js
- **Сборщик:** Vite
- **Стилизация:** Tailwind CSS
- **Маршрутизация:** React Router
- **Развертывание:** GitHub Pages

## Структура проекта

- **`/` (корень):** Содержит файлы конфигурации (`vite.config.js`, `tailwind.config.js`, `package.json`) и данный `README.md`.
- **`/src`:** Основная папка с исходным кодом приложения.
  - **`/src/components`:** Переиспользуемые React-компоненты (кнопки, карточки, лейауты).
  - **`/src/pages`:** Компоненты, представляющие собой отдельные страницы приложения (Главная, Маркетплейс, Лента и т.д.).
  - **`/src/assets`:** Статические ассеты, такие как изображения (иконки, логотипы), которые импортируются напрямую в компоненты.
  - **`/src/data`:** Моковые (временные) данные для наполнения компонентов.
  - **`App.jsx`:** Корневой компонент приложения, где настраивается маршрутизация.
  - **`index.css`:** Глобальные стили и определение цветовой схемы проекта.
- **`/public`:** Папка для статичных файлов, которые не проходят обработку сборщиком, а напрямую копируются в корень итоговой сборки.
- **`/docs`:** **Важно!** Папка, в которую собирается готовая к публикации версия сайта. Именно из этой папки GitHub Pages развертывает ваш сайт. Она генерируется автоматически при выполнении команды `npm run build`.

## Основные страницы

- **Лендинг (`/`)**: Главная страница для неавторизованных пользователей.
- **Маркетплейс (Лендинг) (`/marketplace-landing`)**: Промо-страница маркетплейса.
- **Главная (`/home`)**: Основная страница для авторизованных пользователей.
- **Маркетплейс (`/marketplace`)**: Основная страница с каталогом продуктов.
- **Лента (`/feed`)**: Социальная лента с постами.
- **Персоны (`/persons`)**: Каталог пользователей и экспертов.
- **Сообщения (`/messages`)**: Интерфейс для личных сообщений.
- **Избранное (`/favorites`)**: Страница с избранными продуктами/постами.
- **Центр помощи (`/help`)**: Раздел с FAQ, новостями и видеоуроками.

## Система дизайна

### Цвета

Цветовая палитра определена в файле `src/index.css` с помощью CSS-переменных.

- **Основной (оранжевый):** `var(--primary-color)` - `#F97316`
- **Вторичный (темно-синий):** `var(--secondary-color)` - `#1E293B`
- **Акцентный (индиго):** `var(--accent-color)` - `#4F46E5`
- **Фон:** `var(--background-color)` - `#F8FAFC`
- **Основной текст:** `var(--text-color)` - `#0F172A`

### Шрифты

- **Основной шрифт:** 'Unbounded', sans-serif. Подключается из Google Fonts в `src/index.css`.

### UI-элементы

- **Кнопки:** Имеют скругленные углы (`rounded-lg`). Основные кнопки используют оранжевый цвет (`bg-orange-500`).
- **Карточки:** Используются для отображения продуктов, постов, профилей. Имеют тень (`shadow-md` или `shadow-lg`) и скругленные углы.
- **Поля ввода:** При фокусе подсвечиваются оранжевой рамкой.

## Процесс разработки и развертывания

Это **самый важный** раздел. Неправильное выполнение этих шагов приводит к тому, что изменения не появляются на сайте.

### 1. Локальная разработка

Для запуска локального сервера для разработки выполните команду:
```bash
npm run dev
```
После этого сайт будет доступен по адресу `http://localhost:5173` (порт может отличаться).

### 2. Сборка и публикация на GitHub Pages

**Перед каждой отправкой изменений на GitHub необходимо выполнять сборку проекта.**

**Шаг 1: Сборка проекта**

Выполните команду в терминале:
```bash
npm run build
```
Эта команда соберет последнюю версию вашего приложения и поместит ее в папку `/docs`.

**Шаг 2: Добавление и коммит изменений**

После успешной сборки добавьте все файлы в Git и сделайте коммит:
```bash
git add .
git commit -m "Ваше сообщение о том, что вы сделали"
```
*(Пример сообщения: `feat: добавил секцию X на главную страницу` или `fix: исправил отображение кнопки Y`)*

**Шаг 3: Отправка на GitHub**

Отправьте ваши изменения в удаленный репозиторий:
```bash
git push origin main
```

После этого GitHub Pages автоматически начнет обновление вашего сайта. Через 1-2 минуты изменения появятся по адресу [https://sscutushev.github.io/TOT-Test/](https://sscutushev.github.io/TOT-Test/).
