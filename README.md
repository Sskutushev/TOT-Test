# Проект TOT на React

Этот документ описывает текущую структуру проекта, проделанную работу по миграции со статических HTML-файлов на React и рекомендации по дальнейшей разработке.

## Обзор

Проект был успешно перенесен со статической верстки (HTML, CSS) на современный стек с использованием React. Это было сделано для повышения интерактивности, управляемости и масштабируемости приложения.

**Ключевые изменения:**

- **Архитектура:** Проект теперь является Одностраничным Приложением (SPA), управляемым React.
- **Навигация:** Вместо прямых переходов между HTML-файлами используется `react-router-dom` для плавной навигации без перезагрузки страницы.
- **Компонентный подход:** Каждая страница и переиспользуемые элементы (боковая панель, шапка) вынесены в отдельные React-компоненты.

## Процесс миграции

1.  **Инициализация:** Проект был создан с помощью `Vite`, современного и быстрого сборщика для веб-приложений.
2.  **Установка зависимостей:** Была установлена библиотека `react-router-dom` для управления маршрутизацией.
3.  **Структурирование:**
    - Все статические ассеты (папки `css` и `img`) были перенесены в папку `public`.
    - Создана стандартная для React-проектов структура в папке `src`: `components` (для переиспользуемых компонентов) и `pages` (для отдельных страниц).
4.  **Создание компонентов:**
    - Создан корневой компонент `App.jsx`, который управляет всей маршрутизацией.
    - Создан `Layout.jsx`, включающий общую боковую панель (`menupanel`) и верхнюю панель (`TopPanel`), который оборачивает все внутренние страницы сайта.
    - Создана новая страница `LandingPage.jsx` с кнопками "Войти" и "Регистрация".
5.  **Конвертация страниц:** Каждая HTML-страница (`index.html`, `timeline.html`, `marketplace.html` и т.д.) была преобразована в отдельный React-компонент в папке `src/pages`.

## Как запустить проект

Для запуска проекта в режиме разработки выполните следующие команды в корневой папке:

1.  **Установка зависимостей:**
    ```bash
    npm install
    ```
2.  **Запуск сервера разработки:**
    ```bash
    npm run dev
    ```

После этого приложение будет доступно по адресу `http://localhost:5173` (или по другому порту, указанному в терминале).

## Структура Проекта

- `public/` - Статические файлы. Сюда входят `css/styles.css` и все изображения `img/`.
- `src/` - Исходный код приложения.
  - `src/components/` - Переиспользуемые компоненты (`Layout.jsx`, `TopPanel.jsx`).
  - `src/pages/` - Компоненты, представляющие собой отдельные страницы (`HomePage.jsx`, `TimelinePage.jsx` и т.д.).
  - `src/data/` - Моковые (тестовые) данные.
  - `src/routes.js` - Конфигурация маршрутов.
  - `src/App.jsx` - Главный компонент, где настраивается роутинг.
  - `src/main.jsx` - Точка входа в React-приложение.
- `package.json` - Файл с описанием проекта, зависимостей и скриптов.

## Основные зависимости

- `react`: Основная библиотека для построения пользовательского интерфейса.
- `react-dom`: Связующее звено между React и DOM-деревом в браузере.
- `react-router-dom`: Библиотека для реализации маршрутизации в приложении.

## Стиль кода и дальнейшая работа

Для поддержания чистоты и консистентности кода рекомендуется придерживаться следующих правил:

- **Компоненты:** Создавать функциональные компоненты с использованием хуков (`useState`, `useEffect` и т.д.).
- **Стилизация:** Все стили должны быть вынесены в отдельные CSS-файлы, соответствующие компонентам. Использование инлайн-стилей не рекомендуется.
- **Новые страницы:** При добавлении новой страницы создавать для нее файл в `src/pages/` и прописывать новый маршрут в `src/routes.js`.
- **Переиспользуемая логика:** Сложную или повторяющуюся логику выносить в кастомные хуки (папка `src/hooks/`).
- **Данные:** Все моковые (тестовые) данные должны храниться в директории `src/data`.

## Руководство по стилю

### Цвета

- **Основной оранжевый:** `#FF7A00` (используется для кнопок, ссылок и акцентных элементов).
- **Основной черный:** `#333` (используется для основного текста).
- **Серый текст:** `#666` (используется для второстепенного текста).
- **Фон:** `white` (основной фон), `#FFF5EC` (фон для выделенных элементов).
- **Границы:** `#E3E3E3` (основной цвет границ).

### Кнопки

- **Основная кнопка:** класс `button-withicon` или `button-small-withicon`.
- **Кнопка настроек:** класс `settings-button`.
- **Кнопка выхода:** класс `logout-link`.

### Шрифты

- **Основной шрифт:** (не указан в коде, используется шрифт по умолчанию).
- **Размеры шрифтов:**
    - `1.4rem` (заголовки h2 в попапах)
    - `1.1rem` (заголовки h3 в дропдаунах)
    - `1rem` (заголовки h3 в секциях попапов)
    - `0.9rem` (основной текст, заголовки h4)
    - `0.8rem` (второстепенный текст)

### Другие элементы

- **Карточки уведомлений:** класс `notification-card`.
- **Выпадающие меню:** классы `notification-dropdown`, `profile-dropdown`.
- **Активная ссылка в меню:** класс `active-link`.
