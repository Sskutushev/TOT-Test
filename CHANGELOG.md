# Журнал изменений

## [YYYY-MM-DD]

### Добавлено

- **Дропдаун уведомлений:** В `TopPanel` добавлено выпадающее меню для уведомлений.
- **Дропдаун профиля:** В `TopPanel` добавлено выпадающее меню для профиля пользователя.
- **Страница уведомлений:** Создана и стилизована страница `NotificationsPage` для отображения всех уведомлений.
- **Иконки:** Добавлены иконки для элементов меню профиля и других новых элементов интерфейса.

### Изменено

- **Попап "Создать":**
    - Переработан для более компактного вида, убран скролл.
    - Элементы теперь располагаются в одной колонке для лучшей читаемости.
- **Кнопка "Выход":** Теперь является полноценной ссылкой, ведущей на главную страницу, имитируя выход из системы.
- **Кнопка "Смотреть все уведомления":** Теперь является полноценной ссылкой, ведущей на страницу всех уведомлений.
- **Центрирование логотипа:** Логотип в боковой панели теперь отцентрирован.

### Рефакторинг

- **Стилизация:**
    - Все инлайн-стили были вынесены из компонентов (`TopPanel.jsx`, `CreatePopup.jsx`, `NotificationsPage.jsx`, `Layout.jsx`) в отдельные CSS-файлы (`TopPanel.css`, `CreatePopup.css`, `NotificationsPage.css`, `Layout.css`).
    - Это улучшило читаемость, поддерживаемость и масштабируемость кода.
- **Компонентная гранулярность:**
    - `TopPanel.jsx` был разбит на более мелкие компоненты: `NotificationDropdown.jsx` и `ProfileDropdown.jsx`.
    - `NotificationsPage.jsx` был разбит на `NotificationCard.jsx` и `SettingsModal.jsx`.
- **Управление данными:**
    - Все моковые (тестовые) данные были вынесены в отдельную директорию `src/data`.
    - Созданы файлы `notifications.js`, `profileMenu.js`, и `createPopup.js` для хранения соответствующих данных.
- **Роутинг:**
    - Конфигурация маршрутов была вынесена в отдельный файл `src/routes.js` для улучшения читаемости и управляемости.
    - `App.jsx` теперь использует этот файл для рендеринга маршрутов.
